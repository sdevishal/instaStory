# Instagram Story Feature

A lightweight Instagram-style story feature built using React.  
Users can upload image stories, view them in a full-screen modal, and experience automatic story progression and expiration.

## Features

- Upload image stories
- Story preview panel
- Full-screen modal view
- Automatic story transition every 15 seconds
- Auto-expiry of stories after 15 seconds


## Key Concepts

- React state management (`useState`)
- Conditional rendering
- File handling
- Timer-based UI logic


## Goal

To demonstrate real-world frontend logic and state handling similar to Instagram Stories.
